## 6. D1–D3 实际发现与修复

1. CI images job 用 Compose build 会因 `.env` 必填变量失败；改为直接 `docker build`。
2. Docker 环境无 buildx，classic builder 可用；多架构未验证。
3. 容器前端页脚未更新 D1，重建镜像后重拍。
4. Compose app profile 与 host 开发端口分离（18080/18081 vs 8080/5173）。
5. D2 `security-check.sh` 使用 bash 只读变量 `UID` 导致失败，改成 `CONTAINER_UID`。
6. D2 备份文件默认权限过宽，脚本增加 `chmod 600`。
7. D3 状态接口 P95 约 225ms，明显高于缓存菜单 30.94ms；未做进一步 DB 慢查询分析。
8. 没有不可变镜像 tag/registry，未做真实回滚演练；未编造远程 CI、registry、镜像扫描结果。
